# Laboratorio de Capa Física - Capítulo 8

Simulador interactivo para el caso "¿Por qué no imprime?" de la materia Redes (UCEL).

## Cómo abrir
1. Descargar o clonar la carpeta.
2. Abrir `index.html` en cualquier navegador moderno.
3. No requiere servidor ni internet (funciona 100% offline).

## Estructura
- `index.html`: estructura HTML (pestañas Simulador y Diagnóstico).
- `css/styles.css`: estilos, temas claro/oscuro.
- `js/app.js`: modelo físico, mapa de calor y lógica de diagnóstico.

## Uso
- **Simulador**: arrastrá la impresora para ver el mapa de calor. Cambiá banda, microondas, notebooks y cable UTP.
- **Diagnóstico**: marcá síntomas y el sistema prioriza las causas del Capítulo 8.

## Nota
Modelo simplificado de propagación. No son mediciones reales.
